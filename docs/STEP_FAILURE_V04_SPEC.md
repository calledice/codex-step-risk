# 每步最终失败概率 0.4.0

状态：ALIGNED。来源：2026-10-10 用户要求重新设计开发，每个 step 都给出可能引起最终任务失败的概率；允许由算法或 Luna 计算。此前仅结构化数据的限制经本轮询问后由用户授权采用代理建议的脱敏上下文摘要方案。

## 产品含义

主指标定义为：在该步骤完成时可见的信息下，模型估计该步骤引入或遗留的问题最终仍未消除，并对当前会话目标的失败产生实质影响的概率。

每步是一个独立的多标签事件：同一次最终失败可涉及多个步骤，各步百分比无需总和为 100%。这不是排查名次、重要程度或旧版归一化责任份额。概率为模型预测，未经经验验证；校准不作为显示数值的前置条件。

“任务”默认是所选会话的用户目标，可在页面填写目标和验收要求；回合只用于浏览分组。未提供目标时按通用完成要求估计并标记依据较少。可观测 step 为工具完成与子 agent 完成；不虚构不可观测内部思考步骤。Stop 仅结束回合，不代表任务成功。

## 计算与数据

- 本地默认模型使用条件链 `p = problem × persistence × impact`：本步引入/留下相关问题；在已有问题条件下直到结束仍未消除；在问题存在且未消除条件下导致最终目标失败。三者是顺次条件概率，不依赖独立性假设。
- 未知、普通成功、明确动作失败均有数值。默认先验公开；未知输出不会自动视为成功，诊断步骤报告错误不会自动等同制造错误。
- 所有新日志写入每步规则估计，旧日志在读取时重算，不篡改历史原始记录。旧责任字段仅用于兼容，不出现在新页面主区。
- Luna 返回三因素、证据引用、摘要和限制，由本地程序验证范围后相乘。不得直接采用不合法数值或没有有效引用的内容。失败时保留规则估计并提供具体错误。
- 预测使用本步骤及至多 6 个同回合前序步骤，不能偷看后续结果；保存后不因无关后续成功而降低历史预测。修改任务目标或数据模式后使相关缓存失效。页面明确这是预测时点的估计，而非最终定责。
- 任务目标、步骤动作及响应摘要在本地限长并过滤常见敏感字段、Bearer/API key、token、密码和私钥。发送前页面可查看摘要。新插件的默认数据模式是仅结构化；此用户本地设置启用脱敏摘要，设置和凭据不进入 ZIP。配置提供方和 env_key 继续复用 config.toml。

## 页面与调用

采用可在窄侧栏阅读的步骤卡片：明显的每步概率、估计来源、证据质量、一句话原因、折叠的因素和原始观测。取消固定 20% 总任务风险、残余份额和责任排名作为主指标。提供按时间/风险排序。

页面允许设置会话目标、选择结构化或摘要模式、逐步 AI 评估、评估当前回合及自动评估新步骤。初次打开不自动补跑全部历史；批量每次至多 10 步，网络请求串行。仅页面打开时处理新步骤，Luna 不阻塞 hook。AI 缓存存在本地，自动刷新不会重复调用或丢失结果。

## API 约定

每个 dashboard event 增加 `stepFailure`：`{modelVersion,status:'model_estimate',value,source:'rules'|'luna',factors:{problem,persistence,impact},evidenceQuality:'low'|'medium'|'high',summary,reasons:string[],limitations:string[],evidenceRefs:string[]}`。本地 source 为 rules，Luna 结果为 luna；显示值只能为三个合法因素之积。

`GET /api/dashboard` 追加 `version:'0.4.0'`、`taskSettings:{goal,dataMode,autoAssess}`。`POST /api/settings` 接收 `{sessionId,goal,dataMode,autoAssess}`，只改所选会话。`POST /api/assess` 接收 `{sessionId,turnId,ordinal}`，返回 `{assessment,cached}`；具体错误复用安全错误契约。`GET /api/evidence?sessionId=...&turnId=...&ordinal=...` 返回实际会发送的脱敏 evidence。所有写入接口保留 Origin、Host、体积和输入验证。

## 验收

- AC-1 每个可见新旧步骤均有 0 到 100% 的模型估计。
- AC-2 无归一化，不从旧 taskRisk/pCurrent 相乘；加入无关步骤不改变已有规则值。
- AC-3 单独展示成功/失败/未知的观测事实；未知也有概率。
- AC-4 有目标与摘要时 Luna 能输出与步骤相关的判断；非法输出不覆盖规则值。
- AC-5 缓存持久化；重启、刷新不重复付费；目标/数据变更失效；网络不进入 hook。
- AC-6 主页面在桌面侧栏能直接看到步骤与概率，无需横向拖动表格。
- AC-7 对隐私边界、失败降级、缓存、并发、旧日志与真实 UI/API 进行验证。
- AC-8 更新本机插件与用户级 hook 路径，重启两个现有面板，提供 0.4.0 ZIP。实际宿主是否热加载新 hook 单独核验。

## 验证限制

测试证明计算、数据边界和产品流程按约定运行，不证明预测已准确或因果已验证。未来可用真实终局结果评估概率质量，但当前交付不以收集这些数据为前置条件。
